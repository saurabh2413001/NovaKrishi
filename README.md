# NovaKrishi — Production-ready Flutter + API starter

NovaKrishi is a responsive farmer marketplace app with English/Hindi UI, phone OTP authentication, live mandi-price integration, live weather integration, crop-image support, marketplace APIs, orders, cart, AI hooks, and backend authentication.

## 1. Flutter app

From the project root:

```bash
flutter create --platforms=android .
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:5000/api
```

For a physical Android phone, replace `10.0.2.2` with the Ubuntu computer's LAN IP, for example:

```bash
flutter run --dart-define=API_BASE_URL=http://192.168.1.20:5000/api
```

The Android platform files are intentionally generated by the Flutter SDK on the target machine so they match the installed Flutter/Gradle/Android toolchain.

## 2. Backend

```bash
cd backend
npm install
cp .env.example .env
npm run dev
```

### MongoDB

Set `MONGODB_URI` to a local MongoDB or MongoDB Atlas connection string. The authentication and order/product persistence services use MongoDB.

## 3. Real farmer OTP by SMS

NovaKrishi uses **Twilio Verify v2** for production phone OTP. Twilio Verify creates and checks the six-digit verification code; the app never needs to receive the secret from the server.

Create a Verify Service and set:

```env
TWILIO_VERIFY_ENABLED=true
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_VERIFY_SERVICE_SID=VAxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

Then restart the backend.

For India, use the farmer's 10-digit number; NovaKrishi converts it to `+91XXXXXXXXXX` before sending.

Do not put Twilio secrets in Flutter source code or commit them to git.

## 4. Live mandi prices

The backend is already wired to the Government of India's OGD/Data.gov.in mandi resource:

```env
MANDI_API_KEY=YOUR_DATA_GOV_IN_API_KEY
MANDI_API_URL=https://api.data.gov.in/resource/9ef84268-d588-465a-a308-a864a43d0070
```

Without a key, the API returns the bundled fallback dataset and clearly marks the response as non-live.

## 5. Live weather

Set:

```env
OPENWEATHER_API_KEY=YOUR_OPENWEATHER_KEY
OPENWEATHER_DEFAULT_CITY=Gorakhpur,IN
```

The server calls OpenWeather's Current Weather API and returns a small stable NovaKrishi response to Flutter.

## 6. Images

Marketplace product records already support `imageUrl`. The UI renders remote crop images when the backend provides them and falls back to the local crop icon if an image fails. Seed products use public agricultural image URLs.

## 7. API base URL

Never hard-code a phone's LAN address into production. Use:

```bash
flutter run --dart-define=API_BASE_URL=https://api.example.com/api
```

For production, put the API behind HTTPS.

## Important production notes

- Real SMS requires an active Twilio Verify configuration and applicable sender/compliance requirements.
- Live mandi prices require a valid Data.gov.in API key.
- Live weather requires an OpenWeather API key.
- MongoDB is required for persistent farmer accounts and orders.
- Crop-photo AI is an integration seam: the backend endpoint should be connected to the model/provider you choose before treating its diagnosis as medical/agronomic advice.
